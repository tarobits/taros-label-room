# Email illustrations

These decorative, transparent PNGs are displayed at 180 × 120 pixels. Each email
embeds only its selected illustration as an inline MIME part, so opening an email
does not fetch artwork from a remote server. Essential content and actions never
depend on the image.

| File | Symbol / LED | Emails |
| --- | --- | --- |
| `email-printer.png` | Plain label / indigo | General updates and approval reminders; unknown event types |
| `email-printer-check.png` | Checkmark / green | Email verification and completed prints |
| `email-printer-warning.png` | Amber warning triangle / red | Blocked printers, empty or needed tape, and print reviews |
| `email-printer-password.png` | Three asterisks / indigo | Password reset requests and password-change notices |

Notification variants are selected from structured event types, never message
wording or translated titles. Every asset has the same 360 × 240 pixel canvas and
works on the light and dark email surfaces.

Created with the built-in image generation tool from the approved “A little label
charm” email concept. Final prompt: preserve the friendly ivory label printer,
charcoal top, indigo button and rays, and curling white label with two indigo lines;
remove the email layout, text, background, ground oval and glow; retain transparency
and an opaque printer and paper for both light and dark backgrounds.

Variant prompts (built-in image generation, using the original printer as reference):
preserve its identity, framing, proportions, ivory body, charcoal top, dark outlines,
curling white paper, indigo rays and transparency; replace only the two printed
lines with a bold indigo checkmark, an amber warning triangle with a charcoal
exclamation mark, or exactly three bold indigo asterisks. No extra objects or words.
Follow-up edits change only the round front LED to green for the check variant and
red for the warning variant, retaining indigo for the password variant.
